## Run locally

Because this is a static site, no package installation is required.

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

## Deployment

The site is configured for GitHub Pages from the `main` branch. Push changes to `main` and GitHub Pages will publish the root directory. The expected public URL is:

`https://amrutha-k20.github.io/amrutha-k20/`
